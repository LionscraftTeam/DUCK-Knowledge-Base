# 🎯 Journey ahead


## Content Updates

Working in [a public GitHub repository](https://github.com/lidofinance/valos/), based on feedback received we propose updates on a continuous basis, as the "Validator Operation Standard (ValOS)". We expect to publish stable versions for reference on periodically, perhaps every 6-18 months. Those versions may receive minor editorial cleaning, such as updates to their status (in particular when they are superseded by a newer stable version), or typos and markup corrections, but their technical content will not be chagend after publication.

The [latest accepted update proposal](https://lidofinance.github.io/valos/spec-update-draft.html) is in the main branch of the [ValOS GithHub repository](https://github.com/lidofinance/valos/).
Open issues and work in progress are also visible in that repository.

Some work we aim to produce in the next update:

* **Single-page Specification** - We aim to produce a single-page specification that can easily be downloaded, printed etc.
* **Rationalisation** - Where there are currently multiple risks covering the same problem, we aim to consolidate them for easier reference
* **Checklist** – An easy-to-use checklist of controls, that references risks, and mitigations.

In a further update, or if someone contributes the necessary work, we may consider:

* **Historic Slashing Overview** – Link historic slashing causes to mitigations, highlighting prevention measures
