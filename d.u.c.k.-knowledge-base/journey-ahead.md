# 🎯 Journey ahead


## Content Updates

Working in [a public GitHub repository](https://github.com/lidofinance/valos/), based on feedback received we propose updates on a continuous basis, as the "Validator Operation Standard (ValOS)". We expect to publish stable versions for reference will be published every 6-18 months. Those versions may receive minor editorial cleaning, such as updates to their status (in particular when they are superseded by a newer stable version), or typos and markup corrections, but their technical content will not be chagend after publication.

The [ValOS GithHub repository](https://github.com/lidofinance/valos/) main branch will reflect the latest accepted update proposal at any given time, while issues and work in progress are also visible there.

Some work we aim to produce in the next update:

* **Single-page Specification** - We aim to produce a single-page specification that can easily be downloaded, printed etc.
* **Rationalisation** - Where there are currently multiple risks covering the same problem, we aim to consolidate them for easier reference
* **Checklists** – Create easy-to-use checklists that combine risks, mitigations, and controls for specific node operator maturity levels

In a further update, or if someone contributes the necessary work, we may consider:

* **Historic Slashing Overview** – Link historic slashing causes to mitigations, highlighting prevention measures
